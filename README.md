## 🧠 Overview

**Push_Swap** is a sorting algorithm project from the 42 curriculum that challenges students to sort data **using only two stacks and a limited set of operations**.  

The goal is to write a program that:
- Takes a list of integers as input  
- Sorts the list using the fewest possible moves  
- Uses only predefined operations (`sa`, `sb`, `ss`, `pa`, `pb`, `ra`, `rb`, `rr`, `rra`, `rrb`, `rrr`)  

This project teaches **algorithm optimization, problem-solving, and efficient use of data structures**.

---

## 🧩 Key Objectives

- Implement a stack-based sorting algorithm  
- Minimize the number of operations used  
- Handle edge cases like duplicates and invalid inputs  
- Ensure robust input validation and error handling  
- Follow **Norminette** rules strictly
